# CrownGrid releases

Release documents define bounded repository milestones. They do not imply that an npm package, Git tag, or hosted deployment was published unless the release explicitly records that evidence.

| Release | Status | Objective |
| --- | --- | --- |
| [0.1 CrownGrid foundation](release-0.1-crowngrid-foundation/README.md) | Implemented in this package | Apply identity, favicon, documentation, support, release evidence, and focused AI workflows |
| [0.2 Essential hardening](release-0.2-essential-hardening/README.md) | Planned | Correct only the highest-value state, optimizer, input, timer, and contact issues |

## Status meanings

- **Planned:** scope and acceptance criteria exist, but implementation evidence does not.
- **In progress:** implementation has started, but acceptance criteria or verification remain incomplete.
- **Implemented:** repository changes and recorded evidence satisfy the story.
- **Deferred:** intentionally removed from the active release without being rejected permanently.
