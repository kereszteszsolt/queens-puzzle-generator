# CG-002: README, support, and contact boundary

## Status

Implemented

## User story

As a visitor or contributor, I want a professional README and clear support channels so that I can understand, run, verify, and support CrownGrid without exposing an email address in repository documentation.

## Acceptance criteria

- [x] Document the exact color-region Queens rules and current cell interactions.
- [x] Provide install, development, build, preview, deploy, documentation, release, privacy, and license links.
- [x] Publish the maintainer website and GitHub profile using the same contact pattern as the related repositories.
- [x] Add a dedicated `SUPPORT.md` for defects and feature requests.
- [x] Add the ways-to-support link and Buy Me a Coffee presentation.
- [x] Do not publish an email address in README or support documentation.
- [x] State that the application uses ephemeral browser memory rather than persistent local storage.

## Evidence

- Root `README.md` and `SUPPORT.md` provide the required information.
- `docs/assets/orange-button.png` supports the repository presentation.
- Contact documentation links only to the website, GitHub, issues, and support page.
