# CrownGrid support

## Get help

Use the repository's [GitHub Issues](https://github.com/kereszteszsolt/crown-grid/issues) for reproducible defects, build problems, or documentation corrections. Search existing issues before opening a new one.

A useful bug report includes:

- the CrownGrid version or commit;
- browser and operating system;
- board size and selected solution target;
- exact steps to reproduce the problem;
- expected and observed behavior;
- console output or a privacy-safe screenshot when relevant.

Do not attach personal information, private browser data, or unrelated files.

## Feature requests

Describe the user problem first, then the smallest behavior that would solve it. Large algorithm, persistence, backend, or framework changes should explain why the current browser-only architecture is insufficient.
