## 📖 About

Queens Game & Generator is an open-source web application that brings a fresh twist to the classic N-Queens puzzle. Thanks to an advanced algorithm, you can generate **billions of unique puzzle variations** with targeted difficulty levels.

### ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Dynamic Color Regions** | Each puzzle features unique color regions that add an extra layer of challenge. Shuffle colors anytime for a fresh look! |
| ⚡ **Smart Generation** | Advanced algorithm creates balanced, solvable puzzles in seconds — optimized for both speed and quality |
| 🎯 **Multiple Difficulty Levels** | From beginner-friendly small boards to expert-level large grids |
| 🔒 **Privacy First** | No trackers, no ads, no accounts required. Fully open source |

### 🎮 How to Play

1. **Choose Your Board** - Select a board size and difficulty that matches your skill level
2. **Place the Queens** - Click on cells to place queens. No two queens can share the same row, column, or be diagonal neighbors
3. **Match the Colors** - Each color region must contain exactly one queen
4. **Solve the Puzzle** - Place all queens correctly without conflicts to win!

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn package manager

### Installation

```bash
# Clone the repository
git clone https://github.com/kereszteszsolt/quens-puzzles-generator.git

# Navigate to the project directory
cd queens-puzzles-generator

# Install dependencies
npm install
```

### Development

```bash
# Start the development server
npm run dev
```

The app will be available at `http://localhost:5173`

### Build for Production

```bash
# Build the project
npm run build

# Preview the production build locally
npm run preview
```

### Deploy to GitHub Pages

```bash
# Deploy to GitHub Pages
npm run deploy
```
